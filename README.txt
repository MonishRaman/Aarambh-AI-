# Aarambh-AI — Team 7 website

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No framework, build step, or package installation is required.

## Before submitting
Open `script.js` and replace these three placeholders in `submissionLinks`:
- `resumesDrive`: already configured with your shared Google Drive folder containing the seven team resumes.
- `presentation`: Google Slides / Drive / PowerPoint share link.
- `demoVideo`: Google Drive / YouTube demo video link.

The GitHub repository is currently set to:
https://github.com/BharathKumarBD/Employee-Onboarding

Make sure each Drive file/folder is shared with the access permissions required by your Dayforce reviewers (for example, anyone with the link can view, if permitted by your institution/company).

## Files
- `index.html` — page structure and project content
- `style.css` — responsive visual design and animations
- `script.js` — resource URLs, mobile navigation, and reveal animations
